Find documents

Search the loaded files by meaning, not just exact words. Bones expands your query with related terms, ranks every file, then judges the closest matches.

Redact & send to Claude

Strip names, companies, and addresses from the loaded material, review the redacted version, then fire it at Claude via the API with a prompt of your choice. Nothing leaves the Mac until you press Send. When the reply comes back, Bones puts the real names back automatically.

No API key set. Add one in Settings → Claude API to use the cannon.

            Local-first. Inference, search, and redaction all run on this Mac via

            v2.7.0 adds shared Memory (teach Bones once, every local model remembers — optionally
