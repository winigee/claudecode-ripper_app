            Local-first. Inference, search, and cleaning all run on this Mac via
            llamafile + a local model. The one exception is “Send to Claude”, which reaches the
            Anthropic API on purpose — and only ever with material you have cleaned first.
          

          

            v2.4.0 adds CLEAN & the cannon — strip names, companies, and addresses from your
            material, review it, then fire the de-identified version at Claude with a prompt from
            the library (or your own). v2.3.0 added Find documents (semantic search in Work).
          

          

            v2.2.0 added Network sharing — open BonesAI in a browser on other devices on the same
            Wi-Fi, or over Tailscale for access from anywhere. Token-protected.
          

          

            Configuration, Brain notes, and chat history live under ~/Library/Application Support/BonesAI/.
